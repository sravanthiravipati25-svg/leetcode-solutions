# 287. Find the Duplicate Number

## Problem

Given an array `nums` containing `n + 1` integers where each integer is in the range `[1, n]`.

There is only one repeated number, but it may appear more than once.

Find and return the duplicate number.

The array should not be modified.

## Examples

### Example 1

```text
Input:
nums = [1,3,4,2,2]

Output:
2
