# 28. Find the Index of the First Occurrence in a String

## Problem
Return the index of the first occurrence of `needle` in `haystack`. Return `-1` if it does not exist.

## Approach
Use C# `IndexOf` with ordinal comparison.

## Key Concepts
- String Search
- `IndexOf`
- String Manipulation

## Complexity
- Time: O(n * m) worst case
- Space: O(1)
